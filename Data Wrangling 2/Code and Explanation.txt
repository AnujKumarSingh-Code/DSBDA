import pandas as pd
import numpy as np
from sklearn.preprocessing import PowerTransformer

# 1. Load the dataset
df = pd.read_csv('academic_performance.csv')
# Expected columns:
# ['roll_no','gender','race_ethni','parental_level_of_education',
#  'lunch','test_preparation_cours',
#  'math_score','reading_score','writing_score','science_score',
#  'total_score','grade']

# 2. Ensure the score columns are numeric
score_cols = ['math_score', 'reading_score', 'writing_score', 'science_score']
df[score_cols] = df[score_cols].apply(pd.to_numeric, errors='coerce')

# Optional: see how many non-numeric got coerced to NaN
print("Non-numeric → NaN:\n", df[score_cols].isnull().sum(), "\n")

# 3. Recompute total_score from the four subjects
df['total_score'] = df[score_cols].sum(axis=1)

# 4. Fill missing values
#  4a. Numeric columns → median
num_cols = score_cols + ['total_score']
for col in num_cols:
    df[col].fillna(df[col].median(), inplace=True)

#  4b. Categorical columns → mode
cat_cols = [
    'roll_no','gender','race_ethni',
    'parental_level_of_education','lunch',
    'test_preparation_cours','grade'
]
for col in cat_cols:
    df[col].fillna(df[col].mode()[0], inplace=True)

print("Missing after fill:\n", df.isnull().sum(), "\n")

# 5. Outlier handling via IQR clipping
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    lower, upper = Q1 - 1.5*IQR, Q3 + 1.5*IQR
    df[col] = df[col].clip(lower, upper)

# 6. Transform total_score
#  6a. Log transform to reduce skew
df['total_score_log'] = np.log1p(df['total_score'])

#  6b. Yeo-Johnson power transform to approximate normality
pt = PowerTransformer(method='yeo-johnson', standardize=True)
df['total_score_pt'] = pt.fit_transform(df[['total_score']])

# 7. Quick final summary
print("Head of processed DataFrame:\n", df.head(), "\n")
print("Summary statistics:\n",
      df[num_cols + ['total_score_log','total_score_pt']].describe())

Here’s a clear, line-by-line breakdown of the IQR-clipping block:

```python
# 5. Outlier handling via IQR clipping
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
    df[col] = df[col].clip(lower, upper)
```

1. **`for col in num_cols:`**  
   Loop over each numeric column you want to clean (e.g. `math_score`, `total_score`, etc.).

2. **`Q1 = df[col].quantile(0.25)`**  
   Compute the **first quartile** (25th percentile) of that column—i.e. the value below which 25% of the data fall.

3. **`Q3 = df[col].quantile(0.75)`**  
   Compute the **third quartile** (75th percentile)—the value below which 75% of the data fall.

4. **`IQR = Q3 - Q1`**  
   The **interquartile range**, which measures the spread of the middle 50% of your data.

5. **`lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR`**  
   Define the conventional “fences” for outliers:  
   - **Lower fence**: anything below `Q1 − 1.5·IQR` is unusually low.  
   - **Upper fence**: anything above `Q3 + 1.5·IQR` is unusually high.

6. **`df[col] = df[col].clip(lower, upper)`**  
   **Clamp** every value in the column to that `[lower, upper]` range.  
   - If a value is below `lower`, it becomes `lower`.  
   - If it’s above `upper`, it becomes `upper`.  
   - Otherwise it stays the same.

---

**Why use IQR clipping?**  
- It’s a robust way to “squash” extreme outliers back to reasonable bounds, without completely dropping rows.  
- By using 1.5 × IQR you target the most extreme ~1%–2% of values in a roughly normal distribution, preserving the bulk of your data’s natural variability.



Let’s unpack each piece and dig into the “how” and “why” of the Yeo–Johnson step:

```python
pt = PowerTransformer(method='yeo-johnson', standardize=True)
```

1. **`PowerTransformer`**  
   A scikit-learn class that implements both the Box–Cox and Yeo–Johnson family of power transforms, choosing a data-driven exponent to make your data as close to Gaussian (“bell-shaped”) as possible.

2. **`method='yeo-johnson'`**  
   - **Box–Cox** requires all positive data.  
   - **Yeo–Johnson** extends Box–Cox to handle zeros and negatives too, via a piecewise formula:
     \[
       y(\lambda) = 
       \begin{cases}
         \frac{(x + 1)^\lambda - 1}{\lambda} & \lambda \neq 0,\, x \ge 0, \\
         \ln(x + 1)                         & \lambda = 0,\, x \ge 0, \\
         -\frac{(-x + 1)^{2 - \lambda} - 1}{2 - \lambda} & \lambda \neq 2,\, x < 0, \\
         -\ln(-x + 1)                       & \lambda = 2,\, x < 0.
       \end{cases}
     \]
   - By choosing Yeo–Johnson, we ensure our transform will work even if `total_score` ever contained zero or negative values (unlikely here, but a good general safeguard).

3. **`standardize=True`**  
   After finding the optimal exponent λ for each feature, the transformer will also **shift** and **scale** your data to have mean = 0 and variance = 1. This is handy because many downstream algorithms (e.g. PCA, k-means, regularized regression) assume standardized inputs.

---

```python
df['total_score_pt'] = pt.fit_transform(df[['total_score']])
```

1. **Why `.fit_transform()` instead of `.fit()` + `.transform()`?**  
   - **`.fit()`**: examines your data and **estimates λ** by maximizing the log-likelihood under a normality assumption.  
   - **`.transform()`**: applies the learned formula (with that λ) to actually re-scale your data.  
   - **`.fit_transform()`** does both in one step, returning the transformed array immediately.

2. **Why `df[['total_score']]` (double brackets)?**  
   - Scikit-learn always expects a 2-D array of shape `(n_samples, n_features)`.  
   - `df[['total_score']]` gives you a **DataFrame** of shape `(n_rows, 1)`.  
   - If you passed `df['total_score']` (a Series), you’d get shape `(n_rows,)` and scikit-learn would complain.

3. **What you get back**  
   - A NumPy array of shape `(n_rows, 1)`, where each entry is  
     \[
       \frac{\bigl(\text{total_score}+1\bigr)^{\hat\lambda} - 1}{\hat\lambda}
       \quad\text{(or the piecewise equivalent if negative values)}, 
     \]
     **then** standardized to zero mean and unit variance.  
   - By assigning it to `df['total_score_pt']`, pandas **broadcasts** that single‐column array into a new Series in your DataFrame.

---

### Why bother?

- **Reduces skew**: raw score distributions often pile up toward 100 or 0; the power transform “stretches” the left tail and “compresses” the right tail to produce a more symmetric shape.
- **Improves modeling**: many statistical tests and models perform best (or assume) roughly normal residuals or inputs.
- **Handles zeros/negatives**: unlike plain log-transform, Yeo–Johnson never blows up at zero.

After this step, `total_score_pt` is a standardized, approximately normal version of `total_score`, ready for any model or analysis that benefits from Gaussian-like inputs.
