```python
import pandas as pd
import numpy as np
from sklearn.preprocessing import PowerTransformer

# 1. Load the dataset
#    Make sure 'weight-height.csv' is in your working directory
df = pd.read_csv('weight-height.csv')
# Expected columns: ['Index','Height(Inches)','Weight(Pounds)']

# 1️⃣ Scan & handle missing values
print("Missing values before:\n", df.isnull().sum(), "\n")
# — here we’ll simply drop any rows with missing data
df = df.dropna()
print("Missing values after:\n", df.isnull().sum(), "\n")

# 2️⃣ Detect & handle outliers (IQR clipping) on numeric columns
num_cols = ['Height(Inches)', 'Weight(Pounds)']
for col in num_cols:
    Q1 = df[col].quantile(0.25)
    Q3 = df[col].quantile(0.75)
    IQR = Q3 - Q1
    lower, upper = Q1 - 1.5 * IQR, Q3 + 1.5 * IQR
    df[col] = df[col].clip(lower, upper)

# 3️⃣ Transform one variable to reduce skew / normalize
#    Let’s apply a Yeo–Johnson power transform to Weight
pt = PowerTransformer(method='yeo-johnson', standardize=True)
df['Weight_transformed'] = pt.fit_transform(df[['Weight(Pounds)']])

# 4️⃣ Quick checks
print("Post-processing summary:\n", df.describe())
```

**What this does:**
1. **Loads** the CSV into a DataFrame.  
2. **Drops** any rows with missing values.  
3. **Clips** outliers in height and weight using the IQR rule (values beyond ±1.5·IQR are set to the fence).  
4. **Transforms** the weight distribution via a Yeo–Johnson power transform (handles zeros and negatives, then standardizes to mean=0, std=1), giving you `Weight_transformed` for modeling or analysis.
