# Step 1: Import libraries
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Step 2: Load the iris dataset
df = sns.load_dataset('iris')  # Inbuilt seaborn dataset

# Step 3: Show the first few rows
print(df.head())

# Step 4: List features and their data types
print("\nFeature Types:")
print(df.dtypes)

# Separate features by type
numeric_features = df.select_dtypes(include=['float64', 'int']).columns.tolist()
nominal_features = df.select_dtypes(include=['object', 'category']).columns.tolist()
print("\nNumeric Features:", numeric_features)
print("Nominal Features:", nominal_features)

# Plot histograms for each numeric feature
df[numeric_features].hist(figsize=(12, 8), bins=15, color='skyblue', edgecolor='black')
plt.suptitle("Histogram for Each Numeric Feature", fontsize=16)
plt.tight_layout()
plt.show()

# Plot boxplots for each numeric feature
plt.figure(figsize=(12, 8))
for i, col in enumerate(numeric_features):
    plt.subplot(2, 2, i+1)
    sns.boxplot(y=df[col], color='lightgreen')
    plt.title(f"Boxplot of {col}")
plt.tight_layout()
plt.show()


#  Step 4: Inference – Compare Distributions & Outliers
#✍️ Observations / Inference:

# All numeric features (sepal length, sepal width, petal length, petal width) are continuous (numeric).

# Petal width and petal length show clearer separations between species in histograms.

# Sepal width shows more variance and outliers (as seen in boxplot).

# There are a few outliers, especially in sepal width.

# Setosa species has significantly smaller petal features compared to others.

This code is performing an exploratory data analysis (EDA) on the famous **Iris dataset** using Python libraries like `pandas`, `seaborn`, and `matplotlib`. Here’s a step-by-step explanation:

### Step 1: Import Libraries
```python
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt
```
- **`pandas`**: A powerful library for data manipulation and analysis.
- **`seaborn`**: A statistical data visualization library based on `matplotlib`, providing a high-level interface for drawing attractive and informative statistical graphics.
- **`matplotlib.pyplot`**: A 2D plotting library used for creating static, animated, and interactive plots.

### Step 2: Load the Iris Dataset
```python
df = sns.load_dataset('iris')  # Inbuilt seaborn dataset
```
- The `seaborn` library has a collection of built-in datasets, and the `iris` dataset is one of them. This dataset contains measurements for three different species of iris flowers (Setosa, Versicolor, and Virginica), with features like `sepal_length`, `sepal_width`, `petal_length`, and `petal_width`.

### Step 3: Show the First Few Rows
```python
print(df.head())
```
- This command displays the first five rows of the dataset, which helps in quickly inspecting the structure and content of the data.

### Step 4: List Features and Their Data Types
```python
print("\nFeature Types:")
print(df.dtypes)
```
- `df.dtypes` shows the data type of each feature (column) in the dataset, helping identify whether they are numeric (e.g., `float64`) or categorical (e.g., `object` or `category`).

### Separate Features by Type
```python
numeric_features = df.select_dtypes(include=['float64', 'int']).columns.tolist()
nominal_features = df.select_dtypes(include=['object', 'category']).columns.tolist()
print("\nNumeric Features:", numeric_features)
print("Nominal Features:", nominal_features)
```
- `select_dtypes(include=['float64', 'int'])` is used to select the numeric features from the dataset, and `select_dtypes(include=['object', 'category'])` selects the nominal (categorical) features.
- The features are then stored in two lists:
  - **`numeric_features`**: Contains the columns with numeric values (e.g., measurements of the flowers).
  - **`nominal_features`**: Contains the columns with categorical values (e.g., species of the flower).

### Plot Histograms for Each Numeric Feature
```python
df[numeric_features].hist(figsize=(12, 8), bins=15, color='skyblue', edgecolor='black')
plt.suptitle("Histogram for Each Numeric Feature", fontsize=16)
plt.tight_layout()
plt.show()
```
- `df[numeric_features].hist()` generates histograms for each of the numeric features (`sepal_length`, `sepal_width`, `petal_length`, `petal_width`).
  - **`figsize=(12, 8)`**: Defines the figure size.
  - **`bins=15`**: Specifies the number of bins in the histogram.
  - **`color='skyblue'`**: Sets the color of the bars.
  - **`edgecolor='black'`**: Adds a black border around the bars.
- `plt.suptitle("Histogram for Each Numeric Feature", fontsize=16)` adds a title to the entire plot.
- `plt.tight_layout()` ensures there is no overlap in the plot layout.
- `plt.show()` displays the plot.

### Plot Boxplots for Each Numeric Feature
```python
plt.figure(figsize=(12, 8))
for i, col in enumerate(numeric_features):
    plt.subplot(2, 2, i+1)
    sns.boxplot(y=df[col], color='lightgreen')
    plt.title(f"Boxplot of {col}")
plt.tight_layout()
plt.show()
```
- `plt.figure(figsize=(12, 8))` creates a figure with the specified size.
- A `for` loop is used to create a subplot for each numeric feature:
  - `plt.subplot(2, 2, i+1)` arranges the boxplots in a 2x2 grid.
  - `sns.boxplot(y=df[col], color='lightgreen')` draws a boxplot for each numeric feature (e.g., `sepal_length`, `petal_length`, etc.). The boxplot displays the distribution of the data, showing the median, quartiles, and potential outliers.
  - `plt.title(f"Boxplot of {col}")` adds a title to each subplot.
- Finally, `plt.tight_layout()` and `plt.show()` ensure the layout is clean and the plot is displayed.

### Summary of What the Code Does:
- It loads the Iris dataset, inspects its structure, and prints the data types of features.
- The dataset is divided into **numeric** and **nominal** features.
- It visualizes the distribution of numeric features with **histograms** and checks their statistical properties (like median, quartiles) using **boxplots**.

These visualizations help in understanding the data better, identifying patterns, and potentially detecting any anomalies or outliers.
